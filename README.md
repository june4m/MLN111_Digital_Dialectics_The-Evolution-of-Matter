# Material Quest

Ứng dụng web học tập tương tác về lịch sử phát triển phạm trù **Vật chất** trong triết học — từ tư tưởng cổ đại đến định nghĩa kinh điển của V.I. Lênin (1908).

## Nội dung

| Section | Mô tả |
|---|---|
| Hero | Giới thiệu và điều hướng |
| Timeline | 6 mốc lịch sử từ triết học cổ đại đến Lênin |
| Ancient Materialism | Ngũ hành Trung Hoa, Anu Ấn Độ, Thalès & Heraclite |
| Scientific Revolution | 5 phát minh (1895–1916) làm rung chuyển vật lý cổ điển |
| Matter Dissolves | Mô phỏng "vật chất tiêu tan" và phản bác của Lênin |
| Lenin Definition | Phân tích 5 cụm từ trong định nghĩa vật chất |
| Category vs Instance | Hoạt động phân loại: phạm trù triết học vs dạng vật chất cụ thể |
| Quiz | 10 câu hỏi trắc nghiệm có giải thích |
| References | Tài liệu tham khảo |

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Framer Motion** — animation
- **Lucide React** — icons

## Chạy dự án

```bash
cd material-quest
npm install
npm run dev
```

Build production:

```bash
npm run build
```
